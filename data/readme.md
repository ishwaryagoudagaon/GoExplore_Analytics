# GoExplore — Data

## 📌 Overview

This folder contains the data used for the GoExplore analytics project.

The data is used to analyse sales performance, products, retailers, countries and order activity, and serves as the foundation for the BigQuery analysis and Looker Studio dashboard.

---

## 📂 Data Source

The original GoExplore dataset was provided as a spreadsheet and used as the starting point for the analysis.

The data was prepared in **Google Sheets** before being loaded into **Google BigQuery** for SQL-based analysis.
